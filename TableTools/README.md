# TableTools

TableTools 是一个 Windows 桌面打表工具，用于递归读取 Excel 表格，按照项目内的表格规则完成解析、合并、校验，并导出客户端/服务器表格数据和客户端 C# 数据代码。

项目以打表功能为核心，其他工具入口暂时保留为占位。本项目不制作安装包或发布版本，直接通过 `run.py` 运行。

## 技术栈

- Python 3.12
- PySide6：桌面 GUI
- openpyxl：读取 `.xlsx`
- xlrd：读取旧版 `.xls`
- 标准库 JSON：配置、表格数据和生成文件清单

字体直接读取当前 Windows 字体，不向项目复制字体文件。

## 环境准备

```powershell
python -m pip install -r requirements.txt
```

建议使用 Python 3.12 或更高版本。

## 启动

```powershell
python run.py
```

程序默认以 1440×960 深色界面启动，支持窗口缩放、白天/晚上/跟随系统主题、简体中文/English，以及侧栏折叠。

## 输入表格

源表放在 `Data` 目录下，工具会递归扫描 `.xlsx` 和 `.xls` 文件，并忽略 `~$` 开头的 Excel 临时文件。

普通表使用固定六行定义区：

```text
第 1 行：table: Skill
第 2 行：字段说明
第 3 行：字段类型
第 4 行：字段名
第 5 行：客户端/服务器标记
第 6 行：默认值
第 7 行开始：数据行
```

单例表在 `table:` 行中使用 `type:single`，通过 `id`、`type`、`data`、`cs` 语义列定义多个配置字段，最终输出为一个包含多个字段键值的配置对象。

同名逻辑表可以分布在多个 Sheet 或多个文件中。工具会按 schema 合并为一个逻辑表；schema 不一致时报告错误并阻断导出。

详细字段类型、数组分隔符、枚举、默认值和错误规则见：

- [表格规则.md](表格规则.md)
- [表格内容规则.md](表格内容规则.md)

## 使用流程

1. 将源 Excel 文件放入 `Data`，子目录会被递归识别。
2. 启动工具，在左侧表列表中勾选源文件。勾选的是文件名，不是逻辑表名。
3. 在右侧切换 Sheet，查看逻辑表名、字段和只读数据预览。
4. 查看“表问题”区域。错误会阻断打表，警告不会阻断。
5. 选择客户端、客户端代码、服务器或服务器代码目标。
6. 点击“打表”。
7. 打表成功后，已勾选的源文件会自动取消勾选。导出目标偏好会继续保存。

同名分表和引用表会自动加入当前导出。字段名为 `逻辑表名_id` 时，会按引用关系递归带入目标逻辑表。

## 输出格式

每个逻辑表独立输出一个 JSON 文件。

普通表：

```json
{
  "Rows": [
    {
      "id": 2001,
      "name": "药水",
      "price": 50
    }
  ]
}
```

单例表：

```json
{
  "team_num": 5,
  "team_num1": 5
}
```

JSON 字段名保留源表写法。客户端 C# 文件按逻辑表生成，命名为：

```text
客户端代码/Item_config.cs
客户端代码/GlobalConfig_config.cs
```

生成的 C# 使用 UpperCamelCase 标识符，并通过 `FormerlySerializedAs` 映射源字段名，包装类型面向 Unity `JsonUtility`。

服务器 JSON 会正常生成。服务器代码生成目前仍为 TODO，勾选框处于禁用状态，不会生成虚假的成功文件。

## 配置和生成文件清单

`settings.json` 只保存用户配置、路径、界面状态、筛选条件、最近文件、收藏和最近打表状态。

生成文件清单独立存放在：

```text
%LOCALAPPDATA%\TableTools\GeneratedFiles.json
```

重新导出时，工具只清理清单中同一目标、同一逻辑表和同一文件类型对应的旧生成文件。用户手工放入的文件、未记录文件和其他逻辑表文件不会被删除。
