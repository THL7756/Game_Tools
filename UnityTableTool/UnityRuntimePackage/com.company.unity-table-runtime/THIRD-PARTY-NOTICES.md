# 第三方依赖

本包随附以下开源程序集，版本与当前桌面工具一致：

- `ExcelDataReader` 3.6.0：MIT License，用于 Unity Editor 读取 `.xlsx`/`.xls`。
- `ExcelDataReader.DataSet` 3.6.0：MIT License，用于把 Excel Sheet 转为表格数据。
- `System.Text.Encoding.CodePages` 6.0.0：MIT License，用于 `.xls` 的代码页编码支持。
- `System.Text.Json` 8.0.5 及其 netstandard 依赖：MIT License，用于 JSON 读取和导出。

对应许可证文本随 NuGet 包发布，源代码和许可证信息可从各项目官方仓库获取。
