# 示例表

`Data` 是示例源表目录，不是导出输出目录。

`技能表.xlsx` 展示完整普通表规则：

- `int()` 使用 `#` 拆分。
- `int()()` 使用外层 `|`、内层 `#` 拆分。
- `int()()()` 使用外层 `;`、中层 `|`、内层 `#`。
- `c`、`s`、`cs` 和空标记。
- `##` 注释列和注释行。
- `#test` 测试列和测试行。
- 同一个 `table: Skill` 可以分布在多个 Sheet；工具会合并分表后校验和导出。

`道具表.xlsx` 展示普通表和 `GlobalConfig` 单例表。单例表第一行带 `type:single`，语义行包含 `id`、`type`、`data`，`desc` 可选；源表可以有多行常量字段，最终合并生成一个单例对象。

工具同时支持 `.xlsx`、`.xls`、`.csv`、`.tsv` 输入。

字段类型速查可直接打开 GUI 的“字段类型”页，包含基础类型、Vector/Color/Quaternion 和一到三维数组示例。

GUI 中的表列表、搜索和最近记录以文件名为主。勾选一张或多张表后，关联表会自动随本次打表导出。每次可以选择只打客户端或只打服务器，结果分别写入 `Data_c`、`Data_s`；两个目录中的 JSON 和 bytes 平铺，且不记录字段端别。C# 单独写入 `Code`，不生成 manifest。

同一个 `table:` 逻辑表的多个文件也属于分表组；例如勾选 `道具表.xlsx` 时，`道具表_1.xlsx` 会自动加入并合并为一份道具表输出。

导出成功后工具会自动取消勾选，并将成功导出的文件加入“最近 10 张”。
