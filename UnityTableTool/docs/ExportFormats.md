# 导出格式

当前 GUI 打表流程输出 JSON 和 C# 数据文件。

- 客户端数据写入设置中的客户端输出目录。
- 服务器数据写入设置中的服务器输出目录。
- C# 数据文件写入项目根目录下的 `Code` 文件夹；只选择一端时直接写入该目录，同时选择两端时按 `Client`、`Server` 子目录区分端别代码。
- 打表完成后工作台会清除本次表勾选；失败时不会清除勾选，并自动展开打表日志。
- 两端同时勾选时分别生成两套文件。
- 字段标记 `c`、`s`、`cs` 或空值只决定字段进入哪一端，不写入最终 JSON。
- 导出目录中的 JSON 平铺，不生成 manifest。
- C# 文件名为 `<表名>Data.cs`，内容由当前选中的逻辑表字段生成。
- `##` 注释行/列和 `#test` 测试行不会导出。

## JSON

每个逻辑表输出 `<表名>.json`，普通表使用 `rows` 数组，单例表使用 `data` 对象。`formatVersion` 表示协议版本，`schemaHash` 表示字段结构指纹。

校验失败时不会替换原输出目录。
