# UnityTableTool 项目实施与验收计划

## 项目目标

把工具整理为稳定的“文件级选择、Sheet 级详情、规则校验、端别导出”流程。界面参考 Figma 设计稿 `3GT69FAnV5wc155OwdCUV7` 的节点 `5:7904`，保留隐藏滚动条和现有快捷操作。

## 处理顺序

1. 文档基线：同步文件/Sheet 层级、字段规则、严重级别、语言包、占位页面和发布目录约定。
2. 核心校验：补齐标量、结构值、数组、默认值、主键、单例、端目标、引用和文件结构检查。
3. 稳定性：语言切换、设置页签和四个占位模块使用安全切换保护，并记录未处理的 UI 异常。
4. 文件与 Sheet：一个源文件在列表中只占一行；详情按真实 Sheet 切换；打开文件、收藏、最近和勾选均按文件处理；详情支持刷新当前文件，Excel 被占用时优先保留内存数据。
5. 视觉与交互：按设计稿调整导航、工作区、文件区、Sheet 标签、问题区、日志区和底部打表区；所有正文、下拉框、日志和表格颜色跟随白天/晚上主题；表格内容居中并显示网格；滚轮行为保留但隐藏滚动条。
6. 输出：JSON 输出继续按客户端/服务器分目录，同时在项目 `Code` 目录生成 C# 数据文件。
7. 编译确认：使用已安装的 .NET 8 SDK 编译 GUI。测试、发布和重新打包暂不执行。

## 验收标准

- 白天模式使用白底黑字，晚上模式使用黑底白字，菜单、Tooltip、问题列表和表格文本都使用动态颜色。
- 语言下拉框至少包含简体中文和 English；切换语言不会关闭窗口，设置页和占位模块也能正常打开。
- 编辑菜单提供撤销、恢复、复制、剪切、粘贴、全选、搜索，并显示快捷键。
- 表列表默认全不选，显示源文件名，不显示多余表头；收藏为空心、已收藏为填充星标。
- 详情使用真实 Sheet 名称；上方逻辑表名来自当前 Sheet；打开按钮打开当前源文件。
- 单例表和普通表都执行完整字段规则；错误红色、警告黄色；`int` 填写字符串必须被拦截。
- 刷新失败时保留已有列表并显示读取错误；成功刷新后列表不为空且选择状态按文件恢复。
- Excel 文件处于打开状态时，已成功读取的内存表仍可直接打表；详情中的“刷新内容”会重新读取当前文件并保持当前 Sheet。
- 成功打表后同时生成 JSON 和 `Code` 目录下的 `*Data.cs` 文件，日志分别报告端数据和 C# 文件数量。
- 设置中的项目根目录、表目录、客户端/服务器输出目录、语言、主题、字体、缩放和快捷键重启后仍保留。
- 首次启动会在程序目录创建 `ToolData/settings.json` 和 `Languages` 语言包目录；安装目录不可写时自动回退到用户本地数据目录。
- 打表成功弹出成功提示并清除表勾选；失败弹出失败提示并自动展开日志。
- 快捷键输入可以直接按组合键；表格内容水平、垂直居中；普通滚轮上下滚动，Shift+滚轮左右滚动。

## 修改范围约束

本轮不重置用户修改的 Excel 文件，不回滚当前工作区已有修改，不重新生成发布目录或压缩包。所有修改的代码文件在文件开头保留用途、日期和作者注释。
