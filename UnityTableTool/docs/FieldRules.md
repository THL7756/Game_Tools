# 字段规则

本文档描述扫描、预览和打表共用的校验规则。问题列表必须保留来源文件、真实 Sheet、单元格或字段和错误码；预览内部使用源坐标定位，但不显示 Excel 原始行号。

## 客户端服务器标记

| 标记 | 含义 | 客户端输出 | 服务器输出 |
| --- | --- | --- | --- |
| 空 | 客户端和服务器 | 包含 | 包含 |
| `c` | 客户端 | 包含 | 不包含 |
| `s` | 服务器 | 不包含 | 包含 |
| `cs` | 客户端和服务器 | 包含 | 包含 |

表头标记只决定字段进入哪次导出。`Data_c`、`Data_s` 中的 JSON 和 bytes 不保存 `target` 或端别信息。

## 注释和测试

- `##` 开头的行或列忽略，不参与校验和导出。
- `#test`、`#ceshi` 开头的行或列参与校验，但不进入最终数据。
- `test_`、`ceshi_` 前缀也按测试列处理。

## 支持的字段类型

`enum(value1|value2)` 是用户自定义枚举类型，成员由 `|` 分隔。枚举值必须来自声明列表；数组中的枚举元素也执行相同检查。

以下类型都必须实际解析，不能把未知类型当作普通字符串放过：

- 标量：`int`、`long`、`float`、`double`、`bool`、`string`
- 结构值：`Vector2`、`Vector3`、`Vector4`、`Color`、`Quaternion`
- 数组：上述类型的一到三维数组，使用本文档规定的 `#`、`|`、`;` 分隔符

结构值使用逗号分隔的固定分量数量；颜色允许 RGB 或 RGBA 四分量；布尔值只接受 `true`、`false`、`1`、`0`。不符合格式时显示红色错误。

## 数组类型

```text
int()       -> 1#2#3
int()()     -> 1#2|3#4
int()()()   -> 1|2#3;4|5#6
```

一维使用 `#`，二维外层使用 `|`、内层使用 `#`，三维外层使用 `;`、中层使用 `|`、内层使用 `#`。最多三维，不支持转义分隔符。数组元素仍使用基础标量和结构值规则校验；空元素、错误层级分隔符和超过三维都属于错误。

## 单例表

第一行使用 `type:single` 标记。前几行包含 `id`、`type`、`data` 的语义行决定字段位置，`desc` 可选且不导出。多行常量字段会聚合为一个输出对象，不要求主键。

单例表仍执行字段类型、数组、默认值、结构值和数据行数量校验。`int` 字段填写字符串、默认值类型错误或结构值分量数量不正确，都必须在检测结果中显示红色错误。

## 严重级别

空文件、空 Sheet、缺少 `table:`、表名为空或普通表定义行不足只写 INFO，不计入问题统计，也不阻断导出。

- 错误（红色）：字段类型/默认值/数组分隔符、主键缺失或重复、单例行数、引用目标缺失、Sheet 或文件结构无法读取等会阻断导出的规则。
- 警告（黄色）：不会改变导出结果但需要提醒的情况，例如非阻断的目录提示。
- 信息：仅用于状态记录，不计入错误和警告统计。

## 表列表和打表

表列表按不含扩展名的文件名展示，超过 7 个中文字符时省略，悬停只显示完整表名；搜索框可以叠加“收藏”“最近 10 张”“所有表”筛选。一个文件只显示一行，文件详情中的 Sheet 标签来自实际读取结果；当前选中的 Sheet 决定详情标题、逻辑表名和预览数据。分表和关联表会自动加入当前导出。客户端、服务器可以分别或同时导出，结果写入 `Data_c`、`Data_s`，代码写入 `Code` 或对应端的子目录。导出成功后自动取消勾选。
