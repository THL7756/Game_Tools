# 字段规则

## 客户端服务器标记

| 标记 | 含义 | 客户端输出 | 服务器输出 |
| --- | --- | --- | --- |
| 空 | 客户端和服务器 | 包含 | 包含 |
| `c` | 客户端 | 包含 | 不包含 |
| `s` | 服务器 | 不包含 | 包含 |
| `cs` | 客户端和服务器 | 包含 | 包含 |

表头标记只决定字段进入哪次导出。`Data_c`、`Data_s` 中的 JSON 和 bytes 不保存 `target` 或端别信息。

## 注释和测试

- `##` 开头的行或列忽略，不参与校验和导出。
- `#test`、`#ceshi` 开头的行或列参与校验，但不进入最终数据。
- `test_`、`ceshi_` 前缀也按测试列处理。

## 数组类型

```text
int()       -> 1#2#3
int()()     -> 1#2|3#4
int()()()   -> 1|2#3;4|5#6
```

一维使用 `#`，二维外层使用 `|`、内层使用 `#`，三维外层使用 `;`、中层使用 `|`、内层使用 `#`。最多三维，不支持转义分隔符。

## 单例表

第一行使用 `type:single` 标记。前几行包含 `id`、`type`、`data` 的语义行决定字段位置，`desc` 可选且不导出。多行常量字段会聚合为一个输出对象，不要求主键。

## 表列表和打表

表列表按文件名展示，搜索框可以叠加“收藏”“最近 10 张”“所有表”筛选。分表和关联表会自动加入当前导出。客户端、服务器可以分别或同时导出，结果写入 `Data_c`、`Data_s`，代码写入 `Code` 或对应端的子目录。导出成功后自动取消勾选。
