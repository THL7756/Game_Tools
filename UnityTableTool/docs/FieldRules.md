# 字段规则

## 客户端服务器标记

| 标记 | 含义 |
| --- | --- |
| 空 | 客户端和服务器 |
| `c` | 客户端 |
| `s` | 服务器 |
| `cs` | 客户端和服务器 |

## 注释和测试

- `##` 开头的行或列忽略，不参与校验和导出。
- `#test` 开头的行或列参与类型和格式校验，但不进入导出数据。
- `#ceshi` 开头的行或列与 `#test` 相同。

## 数组类型

```text
int()       -> 1#2#3
int()()     -> 1|2#3|4
int()()()   -> 1|2_3#4|5_6
```

拆分层级固定为 `#`、`|`、`_`。最多三维，不支持转义分隔符。低维字段出现高维分隔符、出现空元素或类型无法转换时，校验失败。
