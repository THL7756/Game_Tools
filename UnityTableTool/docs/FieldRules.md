# 字段规则

## 客户端服务器标记

| 标记 | 含义 |
| --- | --- |
| 空 | 客户端和服务器 |
| `c` | 客户端 |
| `s` | 服务器 |
| `cs` | 客户端和服务器 |

## 注释和测试

- `##` 开头的行或列忽略，不参与校验和导出。
- `#test` 开头的行或列参与类型和格式校验，但不进入导出数据。
- `#ceshi` 开头的行或列与 `#test` 相同。

## 数组类型

```text
int()       -> 1#2#3
int()()     -> 1#2|3#4
int()()()   -> 1|2#3;4|5#6
```

拆分层级固定为：一维 `#`；二维外层 `|`、内层 `#`；三维外层 `;`、中层 `|`、内层 `#`。最多三维，不支持转义分隔符。低维字段出现高维分隔符、出现空元素或类型无法转换时，校验失败。

## 单例表

第一行使用 `type:single` 标记。前几行中包含 `id`、`type`、`data` 的语义行决定字段位置，`desc` 列可选且不导出，前后端列可以放在任意位置。语义行之后每行表示一个常量字段，单例表最终只导出一个对象，不要求主键。

数据输出目录存放 JSON、bytes、manifest；代码输出目录存放生成的 C# 文件。
