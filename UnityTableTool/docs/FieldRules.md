# 字段规则

## 客户端服务器标记

| 标记 | 含义 | 只打客户端 | 只打服务器 |
| --- | --- | --- | --- |
| 空 | 客户端和服务器 | 包含 | 包含 |
| `c` | 客户端 | 包含 | 不包含 |
| `s` | 服务器 | 不包含 | 包含 |
| `cs` | 客户端和服务器 | 包含 | 包含 |

表头中的标记只用于决定字段进入哪次导出。`Data_c`、`Data_s` 中的 JSON 和 bytes 不保存 `target` 或端别信息。

## 注释和测试

- `##` 开头的行或列忽略，不参与校验和导出。
- `#test` 开头的行或列参与类型和格式校验，但不进入导出数据。
- `#ceshi` 开头的行或列与 `#test` 相同。

## 数组类型

```text
int()       -> 1#2#3
int()()     -> 1#2|3#4
int()()()   -> 1|2#3;4|5#6
```

拆分层级固定为：一维 `#`；二维外层 `|`、内层 `#`；三维外层 `;`、中层 `|`、内层 `#`。最多三维，不支持转义分隔符。低维字段出现高维分隔符、空元素或类型无法转换时，校验失败。

## 单例表

第一行使用 `type:single` 标记。前几行中包含 `id`、`type`、`data` 的语义行决定字段位置，`desc` 列可选且不导出。源表可以有多行常量字段，每行定义一个字段；这些字段最终合并为一个输出对象，不要求主键。这里的“一个对象”不是限制源表只能有一行。

## 表列表和打表

表列表、搜索和最近记录均以文件名标识表。可以勾选一张或多张表；勾选表的关联表即使未勾选，也会随本次打表一起导出。

每次打表选择只打客户端或只打服务器。结果分别写入 `Data_c`、`Data_s`，JSON 和 bytes 在各自目录内平铺；代码单独输出到 `Code`，不生成 manifest。
